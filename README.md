# japan_travel - 沖繩・南國自駕慢遊

陽光活潑版 PWA，適合 GitHub Pages。

## 圖示
- icon-192.png / icon-512.png / maskable-512.png 已換成陽光小太陽 #FFE66D

## 部署
1. 上傳全部檔案到 GitHub repo `rita112025-cpu/japan_travel`
2. Settings > Pages > Deploy from branch: main / root
3. 網址: https://rita112025-cpu.github.io/japan_travel/

## 本地預覽
直接用 VS Code Live Server 開 index.html 即可。
